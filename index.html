What is Oryn Bot?

Oryn is a multipurpose Discord bot project by Oryn Development, focused on server management, moderation, support, and everyday tools.

Are the commands shown guaranteed to work?

No. The command list is illustrative and should be checked against the current bot deployment.

Is the preview connected to Discord?

No. It is a visual concept only and does not show live server data or control a bot.
